# 🎮Please Phone Home
A retro-style top-down space-station adventure made with the fantasy console PICO-8, where you play as an astronaut trying to collect keycards and reach the communication terminal before the station explodes.

## 🛠️ Technology
- `PICO-8`
- `Lua`

## 🚀 Features
- **Top-down movement & collision detection** - navigate the space-station corridors, avoiding walls and obstacles.
- **Collectables & item tracking** - pick up keycards needed to unlock the communication terminal and progress.
- **Sound effects** - adds atmosphere and feedback when interacting with objects or moving.
- **Cross-platform export** - playable on Windows, macOS or Linux if you download the release build; or playable via the PICO-8 Fantasy Console if you prefer to run from source.

## 🧠 The Process
After making games in Java and Python, I wanted to try my hand at making a game with a dedicated engine but still wanted to keep the scope as small as possible, and that is when I discovered PICO-8. With this fantasy console, I was able to build a compact adventure game that combines old-school aesthetics with simple but meaningful mechanics. I turned to PICO-8 because of its limitations - 128×128 display, fixed palette, limited memory and simple audio. This encourages creativity while keeping my scope manageable.

Using PICO-8’s built-in tools, I coded the map, player controls, collision logic, item pickup, sound effects and victory condition entirely in Lua. That made the development loop fast and flexible. I was ableto tweak the map layout or item placement quickly, test behaviours of the obstacles and player, and enjoy the retro “cart-based console” feel. The constraints turned out to be part of the fun, forcing me to design around limited resolution, asset and sound quality, as it allows me to focus on the logic part of the game.

## 📦 Running the Project
1. Download the release folder from the repository; it contains builds for **Windows, macOS, and Linux**.
2. Run the executable for your OS to play right away - no installation required.
3. Alternatively, clone the repo and load the project in PICO-8 if you own it.
4. Control the astronaut using the **arrow keys** to move around the space station, collect keycards and reach the communication terminal!
